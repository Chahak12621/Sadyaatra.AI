# SadYaatra AI Mobile App

This project consists of a FastAPI backend and a React Native (Expo) frontend.

## Frontend Development (Mobile App)
To start the React Native application:
1. `cd frontend`
2. `npm install` (if not already installed)
3. `npx expo start`

## Backend Development (API)
To start the FastAPI server:
1. `cd backend`
2. `pip install -r requirements.txt` (or similar depending on setup)
3. `uvicorn main:app --reload`
